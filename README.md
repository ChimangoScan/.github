# `.github`

This repository is not a tool. It holds the files GitHub reads for the organization as a whole.

| Path | What it is |
|---|---|
| [`profile/README.md`](profile/README.md) | The text shown on [github.com/ChimangoScan](https://github.com/ChimangoScan) |
| [`profile/assets/`](profile/assets) | The images that page uses |
| [`brand/`](brand) | The mark, in the forms we reuse. See [`brand/README.md`](brand/README.md). |

Editing `profile/README.md` on the default branch updates the organization page directly. There
is nothing to build and nothing to deploy.
